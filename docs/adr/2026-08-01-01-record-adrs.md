# Record architecture decisions as ADRs

Date: 2026-08-01
Status: Accepted

## Decision

Significant technical decisions are recorded as ADRs in `docs/adr/`, written
in the same session the decision is made. Accepted ADRs are never edited,
only superseded. Filenames are date-slug; references use slugs.

## Context

Development is AI-driven; decision rationale otherwise lives in chat
sessions that are lost. The webapp phase starts with several genuine
tradeoffs (hosting, stack, data model) that were debated and settled with
the team — without ADRs they would be re-litigated within weeks. ADRs are
the persistent memory layer for both humans and agents; the wiki
(`docs/wiki/`) holds current truth, ADRs hold the why.
