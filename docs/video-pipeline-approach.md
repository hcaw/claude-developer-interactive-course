# Whiteboard Video Pipeline — Approach

_Research date: July 2026. Status: **POC complete and verified** (`output/module-1/m1-02-how-llms-behave.mp4` — sync + determinism confirmed); awaiting look/voice feedback before batch-generating the remaining 43 sections. Operational how-to lives in the [README](../README.md); script.json schema in [script-format.md](script-format.md)._

## Goal

Convert the text-only Claude Developer course (108 markdown articles, 5 modules, 44 sections, ~79k words) into short whiteboard-style explainer videos with AI voiceover, plus an interactive course site — with **zero manual recording or editing**. Every artifact is generated by a repeatable pipeline run by Claude Code; humans only review output.

## Stack decisions

| Concern | Choice | Why |
|---|---|---|
| Video rendering | **Remotion 4** (free tier — ≤3-person company) | Videos as React/TSX (ideal AI-authoring format); deterministic seeded renders; `@remotion/paths` for draw-on animation; best captions/audio ecosystem |
| Whiteboard look | **rough.js** + `evolvePath()` + handwriting fonts (Caveat/Kalam) | Seeded sketchy SVG shapes animated stroke-by-stroke; reads as "whiteboard" without the classic animated hand |
| TTS | **Kokoro-82M** via Kokoro-FastAPI (local Docker, Apache 2.0) | $0, faster-than-realtime on CPU, ~90% of cloud quality, native **word-level timestamps** (the sync signal for drawings + captions). ElevenLabs (~$11–22/course, better warmth) is a possible later upgrade for final renders |
| Delivery (later phase) | Custom static web app | Course checkpoints already contain authored Incorrect/Partial feedback branches — ready-made for an interactive player |

Rejected alternatives (July 2026 research, summarized): Motion Canvas (editor-centric, stale), Revideo (MIT fallback if licensing ever changes), Manim (3B1B aesthetic, not whiteboard), VideoScribe/Doodly (no API), Golpo AI (only whiteboard SaaS API; ~$2/min, non-repeatable), Sora/Veo (nondeterministic, 100–1000× cost), Synthesia/HeyGen/Pictory (avatars/stock montage — can't render exact code/diagrams), OpenAI TTS (no timestamps), Polly generative (no speech marks).

## Architecture

Per-section pipeline; every stage emits a file artifact (inspectable, cacheable, re-runnable):

```
course-content/**/NN-*.md
  │  1. parse            pipeline/parse.mjs — frontmatter + body structure;
  ▼                       splits checkpoint answer keys from questions
build/bundles/<section-id>.json
  │  2. scriptwriting    Claude authors spoken narration + scene spec
  ▼                       (prose is written to be read, NOT heard — rewrite is mandatory)
video-scripts/<section-id>/script.json      ← checked into git; user-editable
  │  3. TTS              pipeline/tts.mjs — Kokoro-FastAPI captioned-speech endpoint
  ▼
public/audio/<section-id>/beat-NN-<beat>.wav + timing.json   (public/ so Remotion can serve it)
  │  4. compose          video/src — ONE generic composition renders any script.json;
  ▼                       word timestamps drive when each element draws
  │  5. render           npx remotion render (seeded → deterministic)
  ▼
output/<module>/<section>.mp4 (+ captions)
```

Design rules:

- **Scene spec is data, not code.** Claude writes `script.json` per section; a single generic Remotion composition renders all of them. No bespoke TSX per video — 44 videos stay consistent and cheap to re-render.
- **Narration scripts live in git** (`video-scripts/`) so review/edit happens on text, never on video.
- **Whiteboard component kit** (built, in `video/src/components/`): `Sketch` (rough.js shapes, seeded), `HandText` (handwriting write-on, optional box), `Bullets` (per-item cues), `CodePanel` (line-by-line draw-in), `Bars` (hand-drawn charts), `TokenStrip` (tokenization visual), `Captions` (active-word highlight). Still to build when the content needs them: `ComparisonBoard` (decision-matrix tables), `Callout` (Setup/Watch-Out blockquote vocabulary).
- Strip the 5 legal disclaimer blocks from narration; keep time-sensitive claims ("verify at build time") intact in speech.

## POC

Target: `course-content/module-1-mso-foundations/02-how-llms-behave/01-teaching.md` — one ~2–4 min video with four concept beats (tokens → context window → sampling → non-determinism), narration, captions, sketch visuals.

Acceptance: Kokoro health + plausible word timings; render completes; captions/drawings land within ~1 word of narration; re-render with unchanged inputs is deterministic; parser runs clean over all 108 files.

After look/voice approval: batch-generate all 44 sections, then build the interactive site (video player + checkpoint player with feedback branches + application steps).
